Repositorio de investigación y experimentación sobre algoritmos de clustering.

## Objetivos

- Comprender los fundamentos del aprendizaje no supervisado.
- Comparar los principales enfoques de clustering.
- Experimentar con K-Means, clustering jerárquico, DBSCAN y GMM.
- Publicar la documentación mediante GitHub Pages.
- Practicar Mermaid, GitHub Wiki, Releases y automatización.

## Algoritmos estudiados

- K-Means
- Clustering jerárquico aglomerativo
- DBSCAN
- Gaussian Mixture Models
